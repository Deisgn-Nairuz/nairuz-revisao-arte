📊 Google Sheets (banco de dados)

Salva os clientes na nuvem via Google Apps Script — sem OAuth, funciona em qualquer máquina.

Cole aqui a URL gerada após publicar o Apps Script abaixo.

📋 Como configurar — faça isso uma única vez

  1. Crie uma planilha no Google Sheets e renomeie a aba para Clientes
  2. No menu da planilha, clique em Extensões → Apps Script
  3. Apague o código existente e cole o código abaixo no editor
  4. Clique em Salvar (ícone de disquete)
  5. Clique em Implantar → Nova implantação
  6. Tipo: App da Web — Execute como: Eu — Quem pode acessar: Qualquer pessoa
  7. Clique em Implantar, autorize e copie a URL gerada
  8. Cole a URL no campo acima e clique em Salvar configurações

Código para colar no Apps Script:

function doGet(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Clientes');
  const cell = sheet.getRange('A1').getValue();
  const data = cell ? cell : '[]';
  return ContentService.createTextOutput(data).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    const payload = JSON.parse(e.postData.contents);
    if (payload.action === 'save') {
      const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Clientes');
      sheet.getRange('A1').setValue(JSON.stringify(payload.data));
    }
    return ContentService.createTextOutput('ok');
  } catch(err) {
    return ContentService.createTextOutput('error: ' + err.message);
  }
}
